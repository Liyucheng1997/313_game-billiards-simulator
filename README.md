# 🎱 台球模拟器 · 中式八球

纯前端（HTML5 Canvas + 原生 JS）的台球游戏，零依赖、零构建。

## 运行

任意静态服务器指向项目根目录即可，例如：

```bash
python -m http.server 8347
```

然后打开 http://localhost:8347 （也可以直接双击 `index.html` 用浏览器打开）。

## 玩法

| 操作 | 方式 |
| --- | --- |
| 瞄准 | 移动鼠标（`←` `→` 微调，`Shift` 更细） |
| 击球 | 在台面按住左键向后拖动蓄力，松开出杆 |
| 加塞 / 高低杆 | 点击左下角白球图标设置击球点（双击复位） |
| 自由球 | 犯规后点击台面放置白球 |

**模式**：单人挑战 AI（新手 / 进阶 / 大师）、双人同屏、练习自由球。

**规则**：中式八球——开球后首次合法进球定花色；清完本方球再打黑8获胜；
白球落袋、误击对方球、击球后无球碰库均为犯规（对手获全场自由球）；
提前打进黑8或打黑8时犯规直接判负。

## 技术要点

- **物理引擎**（`js/physics.js`）：滑动→滚动两阶段摩擦模型，跟进/缩杆由
  接触点摩擦自然产生；三维角速度（滚动轴 + 竖直侧旋轴）；库边反弹含法向
  恢复系数与切向摩擦，侧旋会真实改变反弹角；1/600s 子步长防穿隧。
- **球台几何**（`js/table.js`）：库边按线段建模、袋口断开并带张开的袋角
  斜面，进球需要真实穿过袋口。
- **AI**（`js/ai.js`）：枚举（目标球 × 袋口）候选线路 → 遮挡检测 → 按切角
  /距离/袋型评分 → 高斯噪声按难度扰动出杆；带防洗袋、防误进黑8 的风险
  评估，无进攻线路时打安全球；自由球会采样多点选最优摆位。
- **规则**（`js/rules.js`）：完整中式八球裁决状态机（定花色、连杆、犯规、
  黑8 终局）。
- **音效**（`js/sound.js`）：WebAudio 实时合成碰撞/库边/落袋声，无音频资源。
