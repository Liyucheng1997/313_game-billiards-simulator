# 🎱 台球模拟器 · 中式八球（3D）

纯前端的 3D 台球游戏：three.js 实景球房 + 自研物理引擎，零构建。

## 运行

任意静态服务器指向项目根目录即可，例如：

```bash
python -m http.server 8347
```

然后打开 http://localhost:8347 （也可以直接双击 `index.html` 用浏览器打开）。

## 玩法

| 操作 | 方式 |
| --- | --- |
| 瞄准 | 按住左键左右拖动（`Shift` 精细微调，`←` `→` 微调） |
| 视角 | 左键上下拖动调高低，滚轮远近，`V` 切换杆后视角 / 俯视 |
| 出杆 | 按住右键向下拉（或拖右侧“拉杆”、按住空格）蓄力，松开出杆 |
| 加塞 / 高低杆 | 点击左下角白球设置击球点（双击复位） |
| 辅助线 | `G` 开关 |
| 自由球 | 犯规后点击台面放置白球 |

**模式**：单人挑战 AI（新手 / 进阶 / 大师）、双人同屏、练习自由球。

**规则**：中式八球——开球后首次合法进球定花色；清完本方球再打黑8获胜；
白球落袋、误击对方球、击球后无球碰库均为犯规（对手获全场自由球）；
提前打进黑8或打黑8时犯规直接判负。

## 技术要点

- **尺寸**（`js/table.js`）：真实中式八球台——台面 2540×1270mm、球径 57.15mm、
  圆弧袋角（角袋喉宽约 86mm、中袋约 90mm）。物理和 3D 模型共用同一份几何。
- **物理引擎**（`js/physics.js`，1000Hz 子步）：
  - 球-台呢：滑动→纯滚动两阶段摩擦，过渡点精确求解，跟进 / 缩杆 / 定杆自然产生；
  - 完整三维角速度 + 姿态四元数，球在画面里真实地滚动和旋转；
  - 球-球：恢复系数 + 随滑动速度变化的接触摩擦（投掷效应、旋转传递），
    碰撞回退到精确接触时刻，薄球切角准确；
  - 库边：Han (2005) 模型，接触点高于球心，区分粘着 / 滑动，加塞会改变反弹角和球速；
  - 出杆：按击球点偏移计算旋转，含加塞出杆偏移（squirt）和偏心击球的球速损失；
  - 落袋：球心越过石板开孔后受重力下坠，在袋内碰壁后落底。
- **3D 场景**（`js/render3d.js`）：球房（木地板、墙裙、地毯、杆架、挂画、长椅、壁灯）、
  吊灯三光源软阴影、台呢 / 库边 / 木边 / 袋口内衬 / 台脚建模，
  球面清漆材质 + 环境反射；全部贴图由 Canvas 程序生成，无外部素材。
- **AI**（`js/ai.js`）：枚举（目标球 × 袋口）候选线路 → 遮挡检测 → 按切角 / 距离 / 袋型评分
  → 按难度加高斯噪声；带防洗袋、防误进黑8 评估，无进攻线路时打安全球。
- **规则**（`js/rules.js`）：完整中式八球裁决状态机。
- **音效**（`js/sound.js`）：WebAudio 实时合成，无音频资源。
- **依赖**：`vendor/three.min.js`（three.js r158，已随仓库提供，可离线运行）。
